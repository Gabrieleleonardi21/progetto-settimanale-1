# Portfolio Personale – Gabriele Leonardi

Pagina portfolio personale realizzata come progetto settimanale del corso **Full Stack Developer** di Epicode (2026).

## Descrizione

Sito statico single-page costruito da zero in HTML5 semantico e CSS3, senza framework, con una pagina secondaria dedicata ai progetti.

## Struttura

```
progetto-settimanale-1-1/
├── index.html        # Homepage con tutte le sezioni
├── Progetti.html     # Pagina di dettaglio progetti
└── assets.css/
    ├── style.css     # Stile principale (responsive)
    ├── style2.css    # Stile pagina Progetti
    └── header-bg.jpg # Immagine di sfondo header
```

## Sezioni della homepage

- **Chi sono** – breve presentazione personale con avatar circolare
- **Competenze** – tabella con barre di progresso per HTML5, CSS3, Git, CLI e Markdown
- **Esperienze** – tabella cronologica delle esperienze lavorative
- **Progetti** – card dei progetti realizzati con link a GitHub
- **Contatti** – form con campi nome, email, motivo, data e messaggio

## Progetti in vetrina

| Progetto | Descrizione |
|---|---|
| Registrazione App Musicale | Form di registrazione con input per nome, email e password |
| Clone Home YouTube | Replica del layout della homepage di YouTube |
| Portfolio personale | Questo sito, costruito in cinque giorni |

## Tecnologie utilizzate

- HTML5 semantico
- CSS3 (box model, float, pseudo-classi, pseudo-elementi, media query)
- Google Fonts (Roboto)
- Bootstrap Icons
- Git e GitHub

## Responsive design

Il layout si adatta a tre breakpoint:

- **Mobile** – base, fino a 767px
- **Tablet** – da 768px
- **Desktop** – da 1280px
